Detailed Description

The fft2D class provides an interface to compute the 2D Fast Fourier Transform (FFT) and its inverse. It uses the FFTW library for efficient computation. The class manages the necessary buffers and plans for the FFT operations.

Note
The class is non-copyable but movable. It provides methods for forward and inverse FFT, as well as scaling the inverse transform.
See also
https://www.fftw.org/ for more information on the FFTW library.
