\doxysubsection{Detailed Description}
The \doxylink{class_g_o_a_t_1_1maths_1_1fourier_1_1fft2_d}{fft2D} class provides an interface to compute the 2D Fast Fourier Transform (FFT) and its inverse. It uses the FFTW library for efficient computation. The class manages the necessary buffers and plans for the FFT operations. 

\begin{DoxyNote}{Note}
The class is non-\/copyable but movable. It provides methods for forward and inverse FFT, as well as scaling the inverse transform.
\end{DoxyNote}

\href{https://www.fftw.org/}{\texttt{https\+://www.\+fftw.\+org/}} for more information on the FFTW library. 
\end{DoxySeeAlso}
