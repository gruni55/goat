\doxysubsection{Detailed Description}
Functions for forward and inverse transformations in the angular spectrum framework. 

These routines provide discrete transformations of complex-\/valued fields between spatial domain and spectral domain, as well as scaling operations.

The functions operate component-\/wise on complex fields. Depending on the variant, results are either written to the output field or added to an existing field.
